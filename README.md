## Connect to a PostgreSQL database from the terminal
- Local PostgreSQL setup (quick check)
```
psql --version
```
- Connect to a PostgreSQL db:
```
psql -U postgres
```
- to run an sql file:
```
\i /full/path/to/your/file.sql
```
- Other commands in psql shell:
```
\l        -- list databases
\c dbname -- connect to database
\dt       -- list tables
```
